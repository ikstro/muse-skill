# Example run: Lanework

A complete Muse run on the hero of a landing page for **Lanework**, a fictional task tracker for small teams. Everything here is invented for the example: the product, its facts, its people and its design system (Figtree, SIL Open Font License).

The walkthrough with pictures is in the [main README](../../README.md#example-lanework). This folder holds the run's files, in the order Muse makes them:

| File | Step | What it is |
|---|---|---|
| [`product.md`](product.md) | input | The fictional product sheet: truths T1–T6 and the mock world |
| [`refs/lanework-ds.md`](refs/lanework-ds.md) | input | The design system the run is locked to |
| [`fence.md`](fence.md) | 1 · Fence | Locks, principles, audience, truths, free axes, clichés, selling mechanics |
| [`wide-list.md`](wide-list.md) | 2 · Wide list | 21 directions in the entry shape, seeds and taste tags marked |
| [`jury.md`](jury.md) | 3 · Jury | Blind scores, the buyer's desire in their words, failures, what is missing |
| [`jury-map.json`](jury-map.json) | 3 · Jury | Which jury letter is which list number |
| [`ideas.html`](ideas.html) | 4 · Idea board | Open in a browser: the fence, four featured cards with frame strips, the rest |
| [`comps/`](comps/) | 5 · Comps | Four live first viewports; open any `index.html` in a browser |
| [`comps/BRIEF-common.md`](comps/BRIEF-common.md) | 5 · Comps | The shared brief every comp agent received |

The comps link `comps/lanework-ds.css`, which embeds the font, so they work straight from disk. Each plays for 5–6 seconds and holds; `#t=<seconds>` in the URL jumps to a frame. In «Drag a task. Watch Friday change.» you can drag the cards yourself after the demo.
