# Taste

The owner's standing design preferences, gathered from their reactions during Muse runs. Muse reads this file at the start of every run (fence step) and appends to it at the end (finish step). Entries are soft locks: honour them by default, and say so when a direction deliberately bends one.

Start with this file empty below the headings. The lines under each heading are invented examples that show the format; delete them before your first run.

Format: `- YYYY-MM-DD · <project> · <preference in the owner's own words or a faithful paraphrase>`
